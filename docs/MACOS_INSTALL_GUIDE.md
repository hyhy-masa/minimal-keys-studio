# macOSでのインストールと初回起動ガイド（顧客案内用）

minimal-keys カスタマイズは、Appleの開発者登録（有料）を行っていないアプリのため、
初回起動時にmacOSのセキュリティ機能（Gatekeeper）による警告が表示されます。
**アプリ自体に問題はありません。** 以下の手順で起動できます。

このファイルの内容は、顧客への案内メール・同梱カード・Webページにそのまま転用できます。

---

## お客様向け案内文（コピペ用）

### インストール手順

1. ダウンロードした `.dmg` ファイルをダブルクリックします
2. 開いたウィンドウの中のアプリを「アプリケーション」フォルダにドラッグします
3. アプリケーションフォルダからアプリをダブルクリックして起動します

### 「開発元を確認できないため開けません」と表示された場合

macOSのセキュリティ機能による標準の警告です。次の手順で起動できます。

1. 警告ダイアログは「完了」または「キャンセル」で閉じます
2. アップルメニュー  → 「システム設定」 → 「プライバシーとセキュリティ」を開きます
3. 下にスクロールすると「"minimal-keys カスタマイズ"はブロックされました」という表示があります
4. その横の **「このまま開く」** をクリックします
5. Macのパスワードを入力すると起動します

※ この操作は**初回の1回だけ**です。2回目以降は普通にダブルクリックで起動できます。

※ macOS Ventura / Sonoma（13〜14）では、アプリを**右クリック →「開く」→「開く」**でも起動できます。

### 「壊れているため開けません」と表示された場合

ダウンロード時にmacOSが付ける検疫マークが原因で、ファイルは壊れていません。
「ターミナル」アプリ（アプリケーション → ユーティリティ内）を開き、
以下の1行をコピーして貼り付け、Enterキーを押してください。

```
xattr -cr "/Applications/minimal-keys カスタマイズ.app"
```

その後、普通にダブルクリックで起動できます。

## 開発メモ（まさかず向け）

- 警告の根本原因: アドホック署名（`tauri.conf.json` の `signingIdentity: "-"`）＋Apple公証なし
- 警告を完全になくす唯一の方法は Apple Developer Program 加入（年額約1.5万円）→ Developer ID証明書での署名＋公証。2026-07-02時点で「加入しない」判断済み
- 加入方針に変わった場合は、tauri-actionの署名env（APPLE_CERTIFICATE等）をrelease.ymlに追加すれば自動化できる。その際はClaudeに依頼すればCI設定を整備する
- どちらの警告文が出るかはmacOSバージョンとダウンロード経路で変わるため、案内文は両方をカバーしている
